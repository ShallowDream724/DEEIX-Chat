# 文件预览工作区

## 入口与展示

聊天中的用户附件、回复末尾文件卡片及输入框附件使用同一个预览入口。长文本转成的 TXT 与普通 TXT 一致。正文中的下载链接继续下载，不改变网页引用的行为。

- 桌面复用现有右栏及拖宽操作；文件、Artifact、交互组件只占用一个位置。
- 文件支持最大化、恢复右栏、关闭；同一个文件在尺寸和断点变化时不重新挂载。
- 手机直接在当前工作区展开文件。顶部复用页面的侧边栏与新对话动作，文件名、缩放、下载和关闭接在同一行。
- 工具区悬浮于正文上方，空白区域不拦截操作；正文首部留白随正文滚动。控件使用 DEEIX 的颜色、圆角、焦点与下拉组件。
- 文件名按空间省略或只显示图标，点击浮层展示全名；点空白或再次点击可收起。
- PDF、DOCX、图片与 CSV 显示实际百分比及“适合宽度”；格式不支持缩放时不显示缩放入口。
- PDF、DOCX、图片与 CSV 共用触控板缩放和触屏双指缩放，范围 25%–400%；普通滚动不拦截。控制组外高统一为 32px，文件滚动区使用局部 8px 滚动条。
- 代码文件按文件名识别语言，复用现有 Shiki 高亮器与亮暗主题；代码按文本 token 渲染，HTML 等源码不会执行。高亮超过 200K 字符、5000 行或 30000 token 时保留完整纯文本。
- CSV 只有一个工作表时不显示底部工作表切换标签。
- 附件卡片、文件管理和预览头部共用 `resolveFileIcon`，筛选共用 `resolveFileFilterIcon`。内置 Remix Icon v4.6.0 的 14 个单色 Line 图形，沿用既有图标组件接口与主题色；图标识别不改变上传白名单或模型处理能力。
- 切换文件取消旧加载；切换会话、重新开始临时会话时关闭旧预览。

## 职责边界

`entities/file` 提供 `FilePreviewContent`、各格式 viewer、`FilePreviewPanel`、懒加载入口与文件读取 hook。`FilePreviewDialog` 仅是兼容的模态宿主，知识库等独立入口沿用它；文件管理保留现有列表与详情布局，复用相同格式 viewer。

`ChatFilePreviewContext` 只传递文件及可选 `loadContent`、`allowDownload`。聊天工作区决定右栏位置和互斥状态，`ChatFilePreview` 管理焦点及关闭动作。实体层不依赖聊天或页面导航。

手机头部由 Shell 保留导航，并提供文件控制区挂载点；Panel 仅将 header 放入该区域，正文不被重建。桌面与手机不各挂一份隐藏的 viewer。

## 读取、权限与资源

- 默认 loader 沿用鉴权文件接口；临时附件沿用本地 File loader，共享等独立入口保留自己的读取授权。
- 预览和下载共用本次读取生成的对象 URL，不额外保存文件副本；关闭或换文件时 Abort 并释放 URL。
- fileID 是当前预览请求的身份；普通状态刷新和回调函数重建不重新下载。
- 大二进制附件仅用前 8 KiB 探测文本可读性，不先把整个压缩包解码成字符串。
- PDF 保留页布局，仅为视口附近的页面分配 canvas；离屏取消渲染并释放位图。高倍率单页位图另有限额，避免高 DPI 占用过量内存。
- 缩放、拖动栏宽时先缩放已有位图，停顿 120ms 后重绘并整体替换，避免每次尺寸变化清空画布。
- HTML 文件继续作为代码预览，不被当作可执行 Artifact。没有现成渲染器的格式提供下载。

本批不改数据库结构、存储归属、生成文件保存或鉴权接口。已删除文件在新读取时仍按现有接口报错；已打开预览与删除动作的即时联动属于后续排期。

## 后续范围

PDF 页进度与懒加载缩略图、PPTX/XLSX 新渲染、HTML 执行隔离继续单独安排，不混入基础预览接入。
