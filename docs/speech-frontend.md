# 浏览器语音交互

语音输入统一使用管理员选择的浏览器识别、DeepSeek 完整 WAV 转写，或豆包/微信输入法流式 Opus 通道，不读取旧用户来源偏好。服务器能力目录返回 `selected_input_provider`；每次开始录音先获取新快照，失败时不偷偷切换来源。保存管理员配置会在当前页面及其他标签页失效缓存；可见页面每 15 秒并在聚焦时刷新，同用户共享请求，失效代次保证较早请求不会吞掉后续更新。已开始的录音继续使用其固定来源和有效限制。

浏览器识别优先保留稳定路径。经 UA-CH 品牌/版本或受限桌面 UA 判断为正式桌面 Google Chrome 135+ 时，使用 `start(audioTrack)` 让同一个 `getUserMedia` 音轨同时供原生识别和真实幅度分析，不缓存浏览器识别音频。Android、iOS、未知 Chromium 品牌、WebView 和其他未确认实现不使用该重载；其原生识别没有共享音轨时显示静态状态，不为装饰再开麦克风。该可选重载没有标准能力检测位，兼容分支是针对已知实现的保守判断，不承诺所有浏览器通用，也不试启动识别探测。不支持重载的明确错误会先释放捕获轨道再回退原生入口。浏览器提供 `unspokenPunctuation` 时启用，其余情况保留返回标点。参考：[start(audioTrack)](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/start)、[unspokenPunctuation](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/unspokenPunctuation)。

自主管理的录音只申请一次麦克风，在 AudioWorklet 中连续重采样为 16 kHz 单声道，按实际样本停止。DeepSeek 使用 PCM16 WAV；流式通道使用 20 ms 裸 Opus 包。优先使用 WebCodecs，缺少该能力或原生初始化失败时才创建按需加载的 WASM 编码 Worker。采集与编码队列各最多缓存约一秒，网络待发送缓冲最多 256 KiB。停止先排空采样与编码尾包，再请求本段定稿；取消和切换会话立即释放资源并隔离迟到响应。

非流式 WAV 的 Blob 构造完成后立即清空 PCM 分块引用，等待上传和转写时不继续同时保留两份完整录音；失败不会依赖旧 PCM 自动重试。取消、完成和异常仍统一清理会话与资源。

正常到限按停止录音收尾，返回可开始下一段的状态，不当作浏览器不支持。共享 Web Speech 音轨在样本到限时先进入 stopping 并调用 recognition.stop，停止分析/AudioWorklet 后仍保留该轨道至识别 final/end；完成、取消或最终超时再停轨，避免自己结束音轨引发 audio-capture/aborted 假错误。Chrome 实测 6000 个 20ms PCM 帧在原生 Opus flush 后产生 6001 包，客户端完整发送编码尾包后再 finish，不剪掉可能含末音的额外包；服务端使用有限编码尾窗并按有效录音上限计量。final 抢先于 encoder.flush 完成时，以已确认的会话结果为准，不把后续已关闭编码器误判为本次失败。真实 WS/HTTP 识别失败保留已显示文字，按服务错误与明确超时长错误提示；服务不可用和网络提示不再误标为浏览器能力问题。

DeepSeek 也在录音开始时建立 WAV 识别会话，上传携带 `session_id`、`session_token` 和稳定 `request_id`；取消、失败和离开页对未完成会话发送 DELETE 以释放预留。轨道结束或静音、音频上下文意外挂起、权限撤销、设备移除和 AudioWorklet 异常都会结束录音、停止共享活动，并保留及同步保存已识别文字。取消后的 `getUserMedia` 迟到返回会立即停轨，不恢复录音或进入其他草稿。普通输入仍按已有策略延迟保存；录音停止、取消、失败及 pagehide/beforeunload 使用权威草稿快照同步落盘，瞬间离开也不依赖 250ms 定时器。临时会话仍遵守其不落盘边界，刷新不自动恢复录音。

草稿中每次主动录音拥有独立文本范围，读取 textarea 实际 `selectionEnd` 作为插入位置，不删除已有选区；中间插入保留后文，末尾开始新段默认换行，内部修订只替换该范围。开始录音后聚焦输入框，自动 partial 更新仅在对应文本已提交且输入框仍聚焦时跟随本段末端，不在每次 render 无条件抢焦点。用户主动点击输入框、移动光标/选区或编辑文字即立即结束本段，保留当前已显示的识别文字并同步保存；不等待迟到 final，也不自动发送。再次开始从新的光标位置输入。DeepSeek 非流式在尚未产生转写时被手动打断，会取消未上传的录音会话并丢弃该段音频，仅保留原草稿，不承诺保留尚未转写的录音内容。取消按钮仍只撤销当前录音拥有的文字。录音中主动发送等待定稿，识别失败保留文字供编辑。浏览器识别自动重启后的旧对象迟到错误与结果均按对象身份隔离。

点击录音叉号取消后，输入框聚焦且光标位于保留下来的全文末尾；已有草稿、中间插入和空草稿都遵守此规则，不让迟到 partial/final 恢复已撤销的文本或选区。

录音中的 Enter（包括组合发送快捷键）只停止并定稿保留文字，不调用发送。按住 Enter 到录音结束后的重复 keydown 仍不发送；keyup、失焦或新的非重复按键会恢复普通键盘行为。普通字符、空格、编辑/移动光标、全选/剪切/粘贴、Tab 和 Escape 会结束当前录音并保留已显示文字，同时交还浏览器原生编辑、选区或焦点行为；复制与单独 Shift/Ctrl/Alt/Meta 不改变录音或草稿，不全局拦截系统快捷键。composition 开始时结束网页录音，候选选择交给输入法，确认 Enter 不发送；compositionend 紧邻 Enter 的浏览器事件次序也有局部保护。系统语音输入与网页麦克风可能共享设备，页面不宣称独占，也不猜测系统识别是否启动；只处理实际输入/组合事件或真实麦克风中断。

朗读默认关闭。普通新请求在流缓冲提交并确认助手消息成功之后发布幂等完成事件；恢复、历史读取和失败不会发布该事件。朗读消费当前会话事件，切会话或开始录音会停止播放。完整正文经过规范化后按句段顺序合成，使用累计字符权重线性分段，总预算为 100,000 计费字符和 256 KiB；超过预算明确提示，不截尾。单段服从渠道能力限额，三万字符中文不作为单次上游请求发送。合成按用户、供应商、格式、版本、音色和规范文本去重，重播重新读取相同合成 ID 的音频。未知传输失败保留请求身份，用户手动重试时以同一身份核对原尝试；明确失败、取消或结果不明仅在用户点击“重试朗读”后以新身份及显式重试标志发起新尝试，不自动重新扣费合成。音频过期或 GET 返回 410 时，手动播放至多以一个新身份补建一次，不循环重试。

TTS 使用鉴权 fetch 读取 WAV PCM 流，首次数据即可播放；最多提前排队约半秒音频，暂停停止读取，每段音频有 30 分钟兜底，整篇无累计 30 分钟截断。媒体活动边界接收实际播放 Analyser 的音量，录音和播放共享导航反馈协议，不向消息列表逐帧写状态。

网络返回的单块大小不作为音频合法性条件：代理缓冲或缓存读取可能合并成超过 1 MiB 的块。播放器按最多 32 KiB 的视图逐段消费，保留不足一个 PCM 样本的尾字节，不复制整个网络块；每个解码缓冲最多 4,800 个样本。WAV 头可以跨多个网络块，接受 DeepSeek 的未知长度 `0xFFFFFFFF` 头。暂停、取消和切会话仍使用原有背压与释放路径。

当前 DeepSeek 合成字段为 `text`、`voice_id`、`format=wav`、`filter_markdown=true`；官方不提供语速参数，本站使用默认合成速度，不展示无效语速开关。独立的正文规范化模块移除链接地址、图片和内部标记，保留链接标题；代码、Mermaid 和复杂公式源码替换为短提示，连续省略块合并提示，后续正文继续朗读。表格保留表头与逐行单元格文字，去掉 Markdown 分隔符；这不等于数学口语化或表格语义总结。不会额外调用模型改写朗读内容。直接编辑助手回复会停止该消息旧朗读，保存后按当前正文合成；虚拟滚动卸载按钮不会停止声音。

MiMo 复用同一 WAV 流式播放器，默认冰糖、较快。个人偏好使用 `chat.speech_preferences` 中的渠道对象，字段为 `voice`、`speed`、`style`，缺少字段从当前能力继承默认；DeepSeek 旧 `chat.speech_voice` 仅作为该渠道的兼容来源。参数和渠道参与合成身份，风格恢复默认不会删除其他渠道偏好。配置 hook 使用有效参数的标量依赖，能力轮询返回等值对象不打断播放。MiMo 长文本按能力限额分段，不等全文合成后播放，不并行预生成整篇；停止立即取消音频读取和本地播放并释放 AudioContext，已受理的当前合成段按原有服务端缓存任务完成以供重播，后续段不再提交。

手机切后台时，浏览器允许的音频继续播放，但停止不可见的频谱分析；系统将 AudioContext 挂起或中断时，以 statechange 事件等待恢复，不轮询暂停的音频时钟。返回前台仅对系统暂停尝试一次恢复，保留播放位置，不替用户恢复手动暂停。pagehide（含刷新）立即释放音频读取、分析定时器、监听、排队音源和 AudioContext；刷新后不会自动播放。新页面手动点击会通过相同正文/渠道/参数命中服务端缓存。合成及状态查询同样携带播放 AbortSignal，取消未知结果后保留原请求身份，不因前端中断重复发起新的收费操作。

有序列表在朗读投影中保留实际编号，无序列表按同级顺序生成编号；嵌套层级独立计数，续行和松散列表空行不打断计数，普通段落后新列表重新计数。只修改送给 TTS 的文本，不改聊天正文。用户设置中的“恢复默认”与“朗读风格”标签同排右对齐，并使用真实 label 关联文本框。

文字流在后台保留收到的 delta，暂停渲染帧与节流计时器；回前台或 pageshow 时一次补齐已收到的正文和思考内容，再按原有节奏显示后续数据。停止、清除或切换运行时不会复活旧缓冲。此处理不重发生成请求，不改变服务端运行状态。

共享媒体帧提供独立的 RMS `level` 与可选 `bands`：固定 8 个约 80–8000 Hz 对数频段，使用既有音频图上的 1024 点 FFT、每段实际平均能量与固定 dB 标度，不按当前帧或各段最大值归一化。频谱采样不超过 30Hz，输入/输出缓冲重复使用；录音复用同一个麦克风 source，TTS 复用既有播放 Analyser，媒体元素每个只有一条分析连接。没有共享音轨或频谱接口时不构造假频谱。静音、暂停、停止和卸载清空活动反馈并释放对应连接；输入栏仍可消费 RMS。

输入栏录音操作行使用 32px 圆按钮、24px 波形与 44px 整行高度；透明触区为 40px，不额外占据布局。启动/转写仅显示小 spinner，完整状态保留于屏幕阅读文本；录音时输入框不显示状态占位长文字，最后 10 秒显示简短数字倒计时。

导航使用共享真实频谱驱动横向伸缩和明暗，保持原细线厚度、当前位置与远处条目的颜色/透明度层次。仅左侧位置导航律动，右侧标题目录保持原样。左右边栏同时展开时，正文左内边距从 24px 增至 32px，其余布局不变。低频位于可见条目的中间，高频向上下两端展开；固定 5 帧小缓冲让真实节奏从中间向两端延迟不超过约 133ms，并混合少量全频音量，使边缘条也参与强拍。线条快速起动、平滑衰减，最大约 5 倍长度；没有频谱时保持静态，不由同一 RMS 伪造多条频谱。每帧仅更新可见线条的 transform/opacity，不更新 React 消息树。绘制范围与命中范围分开：96px 滚动绘制层允许覆盖少量正文，24px 导航列处理点击/滚轮，伸长线条 pointer-events:none，菜单位置保持原样。停止、暂停、页面隐藏、减少动态效果或操作导航时重置并恢复原样。
